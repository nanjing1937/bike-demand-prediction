# 共享单车租赁需求预测 —— 实验报告

> 课程作业 | 数据：Seoul Bike Sharing Demand (UCI) | 流程：EDA → 预处理 → 纯神经网络训练评估 → 30% 测试集评估
> 报告中所有数字均由 01~03 三个脚本真实运行产出，random_state=42，可复现。

**版本说明**：本报告对应**纯神经网络极简版**（单层线性网络 + 多层感知机 MLP 主线），与仓库当前代码一致。全流程只使用从零手写的神经网络完成回归——先用单层线性网络建立基线，再用多层感知机拿非线性收益，对应《动手学深度学习》"线性网络 → 多层感知机"的学习路径。网络仅由 Linear 与 ReLU 组成，刻意极简；训练采用两阶段协议（5 折交叉验证定轮数 → 全量重训）；报告中全部模型指标实测自 `inbox/results_pure_nn.json`。

## 一、问题分析

本任务为**回归问题**：给定某小时的天气与时间特征，预测该小时的共享单车租赁数量（`Rented Bike Count`，0~3556 辆/小时）。数据来自韩国首尔 2017-12-01 ~ 2018-11-30 一整年，原始 8820 行 × 14 列。

业务直觉：单车租赁由**通勤需求**（上下班时间刚性）与**休闲需求**（天气敏感）叠加。数据是小时级时间序列，但课程要求按表格回归处理，采用随机划分 30% 测试集——这会带来轻微的时间泄漏（测试集中含训练时段相邻小时），作为课程作业的可接受近似，报告在"已知限制"部分如实讨论。

实验主线分两级台阶：

1. **单层线性基线**：只有一个线性输出层的神经网络，数学上等价于线性回归。它既是学习路径的起点（理解"神经网络是可微分的参数化函数，退化结构即线性模型"），也是协议校验和——若数据管线与训练循环实现正确，其表现应贴住线性回归应有的水平；它还是后续每一分提升的**归因基准**。
2. **多层感知机（MLP）**：三层隐藏层 256-128-64，验证"非线性激活 + 层级特征组合"能吃到多少单层结构吃不到的模式。

两级台阶共用同一份数据、同一个训练循环、同一套评估口径——唯一的变量是**网络结构**，因此两模型间的差异可以干净地归因到结构容量上。

## 二、数据体检（探索性数据分析，图 fig1~fig4）

### 2.1 数据质量体检（关键发现：三类脏数据）

EDA 第一件事不是画分布，是**体检**。本数据被人为埋了三类脏点，若不清洗直接建模会显著伤害结果：

| 脏点 | 数量 | 处理 |
|---|---|---|
| `Seasons` 小写 `winter`、`Functioning Day` 取值 `Y`（大小写错） | 各 80 行 | 统一 Title Case / 映射 |
| 完全重复行 | 60 组 | 删除（去重后 8760 = 365×24，恰好是完整一年的量，说明重复行是人为加入的） |
| 目标列 -1 值（租赁量不可能为负） | 60 行 | 删除（错误记录） |

清洗后 **8700 行**进入建模。脚本内置断言：清洗后行数 ≠8700 直接报错，防止协议漂移。

### 2.2 目标分布（fig1）

目标显著右偏（skewness = 1.16，均值 700 > 中位数 497）：多数时段租赁量温和，通勤高峰与夏季白天出现长尾。log1p 变换后接近正态 → 预处理对目标做 log1p，评估时 expm1 还原。右偏校正对 MSE 训练的网络尤其重要：不做变换时，损失被长尾大值主导，模型会过度迁就极端高峰而牺牲大量中低值时段的精度。

### 2.3 时间模式（fig2）

- **小时**：典型通勤双峰——早 8 点小峰、晚 18 点主峰（均值 1478 辆，全天最高）；凌晨 0-5 点均值仅 288 辆。
- **星期**：工作日与周末差异不大（周末休闲骑行部分抵消通勤损失）。
- **月份**：6 月最高、1 月最低，冬低夏高，符合季节性直觉。

双峰形态是典型的**非线性结构**：租赁量随小时先升后降、再升再降，任何"小时→租赁量"的单调线性映射都无法表达——这为后文"单层线性结构不够用"的实证埋下伏笔。

### 2.4 天气相关性（fig3）

- 皮尔逊与斯皮尔曼相关性高度一致的前列特征：**温度**（0.53/0.56）、**小时**（0.41/0.38）、太阳辐射（0.26/0.38）、露点温度（0.38/0.37）。
- 降雨/降雪相关性低但样本极稀疏（绝大多数为 0）——稀疏的非零信号对回归仍有信息量，交给网络自行取舍。
- **共线性**：corr(温度, 露点温度) = 0.913 > 0.9。EDA 如实记录该发现；本版本特征工程**不做剔除**，19 个特征全部进网络：直接求解正规方程的线性代数解法对共线性敏感（系数方差膨胀），而梯度下降训练的神经网络对共线性的数值稳健性高得多，配合输入标准化即可稳定训练。

### 2.5 类别分组（fig4）

- 季节均值：夏 1027 > 秋 814 ≈ 春 725 >> 冬 226（冬不足夏的四分之一）。
- 节假日均值 495 vs 非节假日 710——节假日整体需求低三成。
- **Functioning Day=No 共 294 行（清洗后，3.4%）租赁量全为 0**：这是"停运时段"而非"需求为零"。选择**保留**这些行：它们是真实业务状态，删行会让模型永远见不到"停运"场景，部署后遇到停运时段会给出荒谬预测；one-hot 出的 `Functioning Day_Yes` 列给网络一条明确的通道去学"停运 ≈ 零租赁"。保留方案对指标是保守的（这些行若预测正确，误差贡献为零），且 FD=No 在训练/测试集中占比一致，无分布偏移风险。

## 三、特征工程与数据准备

预处理协议由 `02_preprocess.py` 定义，`03_train_nn.py` 独立复刻执行（自读原始数据，不依赖落盘产物），两侧行数断言保证口径一致。

### 3.1 清洗管线

修大小写 → 去重 → 删负目标：8820 → 8760 → **8700 行**（详见 2.1）。

### 3.2 特征工程：14 列原始 → 19 个特征

| 步骤 | 内容 | 理由 |
|---|---|---|
| Date 派生 | Month / DayOfWeek / IsWeekend | 捕捉月度季节性与周末效应 |
| Hour 周期编码 | sin/cos(2π·Hour/24) | 23 点与 0 点钟表相邻，原始整数会注入假排序 |
| 类别 one-hot | Seasons(3) / Holiday(1) / Functioning Day(1)，drop_first | 无序类别不能当序数用；drop_first 防虚拟变量陷阱 |
| 目标变换 | log1p(目标) | 右偏校正（见 2.2） |
| 标准化 | StandardScaler（仅训练集 fit） | 神经网络对输入量纲敏感，各特征梯度尺度需拉齐 |

**周期编码对线性结构尤其关键**：单层网络是纯线性映射，若直接喂原始 Hour 整数（0~23），"23 点"会带着最大的正系数权重、"0 点"最小——但两者实际租赁水平接近。sin/cos 把小时映射到单位圆上，让相邻钟点在特征空间也相邻，线性层才有机会用两个分量的组合逼近双峰形态。这也再次说明：**特征工程是在替模型表达它自己表达不了的结构**。

### 3.3 数据划分

`train_test_split(test_size=0.30, random_state=42)`：训练 **6090** / 测试 **2610** 行。测试集全程隔离，只在两模型完全定型后各评估一次，不参与任何训练决策。

### 3.4 标准化与两阶段训练协议

- StandardScaler **只在训练集上 fit** 再变换测试集——防止测试集统计量泄漏进训练过程。
- **阶段一（定轮数）**：`KFold(n_splits=5, shuffle=True, random_state=42)` 切全部 6090 行训练数据，每折内再切 20% 做早停验证（与测试集无关），记录该折最优轮数，五折中位数定为最终轮数。
- **阶段二（全量重训）**：在 6090 行全集上以固定轮数从头重训，无验证集、无早停。用 k 折代替"永久扣 20%"——每个数据点既当训练又当验证，收回早停长期占用 20% 样本的损失；测试集仍只在最终评估一次，口径不变。

## 四、单层线性基线（SingleLayerNet）

### 4.1 设计动机

`nn.Linear(19, 1)`，全模型仅 **20 个参数**（19 权重 + 1 截距），无任何隐藏层，y = Wx + b，数学上就是线性回归。用神经网络框架实现线性模型，三个用意：

1. **学习路径的起点**：先确认自己能在这个手写训练框架里把最简单的模型训到位，再上复杂结构；
2. **协议校验和**：数据清洗、特征工程、训练循环、评估口径任何一环有 bug，这个数字都会偏离线性回归的正常水平——它贴住预期，整条管线才可信；
3. **归因基准**：MLP 相对它的每一分提升，都能归因到"隐藏层带来的非线性容量"，而不是训练技巧或数据差异。

### 4.2 训练配置与结果

手写 mini-batch 训练循环（前向 → MSE → 反向传播 → Adam 步进，零高层封装）。配置：Adam **lr=0.01** / batch **512** / 上限 500 轮 / 早停耐心 50（早停用于阶段一折内验证）；阶段一五折最优轮数为 [224, 204, 200, 272, 185]，中位数 **204** → 阶段二在 6090 行全集上固定 204 轮从头重训。

**结果**（30% 测试集，原始量纲）：MSE 176277.0 / RMSE 419.9 / MAE 267.6 / **R² = 0.5662**。

## 五、多层感知机（MLP）

### 5.1 结构设计

三层隐藏 **256-128-64**（容量阶梯由大到小，逐层压缩到最终输出），每层 `nn.Linear + nn.ReLU`，末层 Linear 到 1，共 **46337 个参数**。本版本网络**刻意不含归一化层、Dropout 等正则化组件**——目的是把结构剥到最简（仅 Linear 与 ReLU），让"非线性容量"成为相对单层基线的唯一变量；防过拟合的任务交给阶段一的早停定轮数承担。

### 5.2 训练配置

与单层完全相同的训练循环，仅超参不同：Adam **lr=1e-3** / batch **256** / 上限 300 轮 / 早停耐心 30。torch 种子固定 42，与单层共用同一初始化种子，保证可比。阶段一五折最优轮数为 [135, 107, 133, 127, 72]，中位数 **127** → 阶段二在 6090 行全集上固定 127 轮从头重训（无验证集、无早停）。

### 5.3 训练过程（fig11）

fig11 给出两网络**阶段二全量重训**的训练损失曲线（log 纵轴）：单层网络快速下降后早早停在平台——那是线性拟合的容量天花板，再训也压不下去；MLP 的损失持续下降到显著更低的水平。两模型的轮数由阶段一五折中位数确定（单层 204 / MLP 127），曲线形态显示在设定轮数内损失均已接近收敛；对 4.6 万参数 vs 6090 行训练数据的容量配比，过拟合控制由阶段一的早停定轮数承担，阶段二按定下的轮数在全部数据上训练。

## 六、结果与讨论

### 6.1 结果（30% 测试集，原始量纲）

| 模型 | MSE | RMSE | MAE | R² |
|---|---:|---:|---:|---:|
| SingleLayerNN（单层基线） | 176277.0 | 419.9 | 267.6 | 0.5662 |
| **MLP 256-128-64** | **44528.0** | **211.0** | **125.7** | **0.8904** |

MLP 相对单层：RMSE 从 419.9 降到 211.0（**下降约 50%**），R² 从 0.566 升到 0.890。

### 6.2 单层 ≈ 线性基线：容量与归纳偏置的含义

单层 R²=0.5662，正是线性模型在这份特征上的应有水平——去掉隐藏层，神经网络的拟合能力就回到线性回归，对照成立。这个数字本身信息量很大：

- **容量视角**：线性模型只能表达"目标 = 各特征的加权和"，本数据的真实结构（通勤双峰、温度甜区、停运即零）远非线性——约 43% 的方差是线性结构原理上解释不了的，只能留给非线性容量去拿。0.566 不是"训练没做好"，而是这一级台阶的天花板。
- **归纳偏置视角**：模型的归纳偏置是它"先天相信"的函数形态。单层网络偏置"全局线性平滑"，与数据的分段/交互结构不匹配；EDA 已经预告了这一点（fig2 的双峰、fig4 的停运断崖都是"平滑假设的负资产"）。
- **工程视角**：它是协议校验和——数字贴住线性水平，证明数据管线、训练循环、评估口径全部无误，MLP 的提升才可信。

### 6.3 MLP 的提升来自哪里：非线性 + 层级特征组合

R² 0.5662 → 0.8904 的提升，来源可以拆成两个互补的机制：

- **ReLU 非线性**：每个 ReLU 神经元是一个软开关——输入超过阈值才激活。三层隐藏叠加后，网络能逼近分段边界与交互效应：`Functioning Day=No → 租赁量≈0` 的断崖、"温度低于阈值需求骤降"的区间效应、"晚高峰 × 工作日"的交互峰，这些是任何线性结构无法表达的形态。
- **层级特征组合**：第一层隐藏单元在 19 个原始特征上学局部模式（如 Hour_cos 与 IsWeekend 的某种组合≈"周末晚归时段"），后层在这些模式之上再组合（"周末晚归 × 温度适宜 × 无降雨"）。交互特征不需要人工穷举构造，层级结构自动完成——这正是"深度"的价值所在。

提升的分布与 EDA 互相印证：fig2 的双峰、fig4 的停运零值、fig3 的温度主导，最终都被网络吃进了 46337 个参数里。

### 6.4 与此前调参版的差异：诚实归因

本项目此前有一版调参更充分的 MLP 实验（含超参网格搜索，网络含归一化层与 Dropout 等正则化组件，最优组合确定后在全部 6090 行训练集上重训），同一测试协议下 R² = 0.9236。当前极简版（升级两阶段协议后）实测 R² = 0.8904，低约 3.3 个百分点。这是**协议差异**，不是随机波动，如实归因：

1. **极简协议删去了正则化组件**：调参版的归一化层与 Dropout 对训练稳定性与泛化有正贡献；极简版刻意全部删去（仅 Linear 与 ReLU），过拟合控制只剩阶段一早停定轮数。
2. **固定轮数代替逐次早停**：两阶段协议以五折中位数定轮数后全量重训，收回了全部 6090 行训练样本，但阶段二无验证集、无最优权重回滚——中位数轮数（127）若偏离本轮最优，训练无法自行修正。相比旧协议（80% 训练 + 早停回滚）的 0.8960，实测 0.8904 低 0.6 个百分点，与固定轮数缺少"逐次验证最优"回滚保证的小代价相符；全量重训的样本增益（6090 vs 4872 行）未在该轮数下转化为优势。"永久扣 20% 验证"的协议缺陷已消除（每个数据点都参与训练），但固定轮数本身引入了新的小代价。
3. **超参未重新搜索**：极简版直接沿用调参结论的 lr/batch/结构，未针对删去组件后的网络重新调参。

各因素各占多少、正则化与训练样本量与轮数确定方式对结果的影响，可作为后续实验方向单独量化（例如固定其余条件、逐项加回组件做消融，或加大折数/改用逐折重训取均值等更稳的轮数确定方式）。

### 6.5 预测散点（fig12）

fig12 为 MLP 在测试集上的预测 vs 真实散点：整体紧贴对角线，中低值区（租赁量的主体）拟合良好；高值区（极端高峰 >2500）略偏低——极端样本稀疏，模型在"迁就长尾"与"守住主体精度"之间取了保守侧，与 log1p 训练目标的压缩效应一致。无系统性弯折，说明误差主要来自容量与样本量，而非口径问题。

## 七、已知限制

1. **随机划分的时间泄漏**：按课程要求随机划分 30%，测试集含训练时段的相邻小时，指标偏乐观；严格做法是时序前向验证（train: 2017-12~2018-09，test: 2018-10~11）或滚动起点验证。
2. **网络刻意极简**：仅 Linear 与 ReLU，不含正则化组件，超参沿用既有结论未重新搜索——6.4 的对比说明还有约 3 个百分点 R² 的改进空间，代价是实验不再"最小"。
3. **未构造时序特征**：滞后特征（t-1 小时租赁量）与滑窗统计通常是时序数据最强特征，但随机划分下引入会造成严重泄漏，需与时序验证配套才有意义。
4. **单城市单年数据**：特征泛化到其他城市/年份需谨慎（未覆盖跨年气候异常）。
5. **FD=No 行未单独报告子集指标**：保留了停运时段行但未另报"运营时段子集指标"；生产场景应分"停运检测"与"运营时段需求"两阶段建模。
