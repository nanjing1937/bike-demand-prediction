# 共享单车租赁需求预测 —— 纯神经网络版本

> 纯神经网络版本，05 单脚本独立跑通。主项目（EDA → 预处理 → 6 模型对比 → 神经网络对照）见 [README.md](README.md)。

## ① 项目介绍

- 定位：对应《动手学深度学习》主线（线性网络 → 多层感知机）的**自包含**实验——从原始 csv 到评估一条命令跑通，不依赖任何前序脚本产物
- 任务与数据同主项目：预测首尔某小时的共享单车租赁量（UCI 公开数据，8820 行 × 14 列）
- 两个模型：单层网络（无隐藏层，数学上≈线性回归，作基线）+ 多层感知机 MLP（网格调参选出结构后全训练集重训）
- 主要结果：MLP R²=0.924 / RMSE=176.2（30% 测试集，原始量纲）；单层 R²=0.568 贴住线性基线；仍低于主项目 XGBoost（0.949），属表格数据的预期结果
- 与主项目的关系：清洗与划分协议复刻 02_preprocess.py、random_state=42 一致 → 测试集逐行相同，数字可与主项目 03/04 直接对照（协议一致，结果同水平）

## ② 运行方式

环境：Python 3.11（3.10+ 均可），依赖见 [requirements.txt](requirements.txt)（含 torch）。

```bash
pip install -r requirements.txt
python 05_pure_nn.py  # 纯神经网络独立版（单层 + MLP）
```

PyTorch CPU 训练。全流程（读原始数据 → 清洗 → 划分 → 单层基线 → 5 组网格 → 最优重训 → 测试集一次评估 → 出图落盘）约 2~3 分钟。

## ③ 实现说明

1. **清洗复刻 02 协议**：类别大小写统一（'winter'/'Y' 各 80 行）→ 删完全重复行（-60，去重后 8760=365×24 恰一整年）→ 删目标负值（-60）→ 8700 行；特征工程 19 列（Date 派生 Month/DayOfWeek/IsWeekend + Hour sin/cos 周期编码 + 类别 one-hot drop_first）
2. **评估口径与主项目一致**：目标 log1p 训练、expm1 还原 + clip(0) 非负截断、原始量纲四指标（MSE/RMSE/MAE/R²）
3. **网格 5 组**：隐藏层 {256-128-64, 128-64-32, 64-32} × 学习率 {1e-3, 3e-4}（最窄的 64-32 只配 1e-3）；其余固定：dropout 0.2 / weight decay 1e-4 / batch 256 / epoch 上限 300 / 早停耐心 30；每组 torch.manual_seed(42)，组间差异只来自超参
4. **防泄漏纪律**：验证集从训练集内再切 20%（1218 行），网格选优与早停只看它；最优组合（256-128-64 @ lr=1e-3）确定后在全训练集（6090 行）重训；测试集（2610 行）只在最终模型定型后评估一次
5. **手写训练循环**（零高层封装）：前向 → MSE → 反向传播 → Adam 步进；训练/评估模式切换控制 Dropout 与 BatchNorm 行为；早停回滚到验证最优权重

## ④ 测试与验证方式

- **重跑幂等**：两次运行 `inbox/results_pure_nn.json` 逐字节一致（md5 相同；网格耗时只打到 stdout 不落盘，避免墙钟波动破坏幂等）
- **结构化核对**：`inbox/results_pure_nn.json` 含两模型四指标、5 组网格 val MSE、最优组合与数据行数（原始 8820 / 清洗后 8700 / 训练 6090 / 测试 2610）
- **合理性范围**：单层 R²≈0.57（应贴住线性基线）；MLP 预期 0.90~0.93；低于 XGBoost 0.949 属预期（原因见主项目实验报告 7.5 节）
- **内置断言**：清洗后行数 ≠8700 或测试集 ≠2610 行直接报错，防协议漂移

## ⑤ 已知限制

- 最优 MLP 重训时轮数贴近 300 上限（最优第 297 轮，验证损失仍在缓慢下降）——上限是为控制网格耗时的小选型，放宽或有零点几个百分点的小空间，不改变与树模型的结论排序
- 未尝试 1D-CNN、类别特征 embedding 化、 wider 搜索（宽度/深度只取 3 档）——改进方向见主项目实验报告第六节
- 随机划分带来的时间泄漏与主项目相同（测试集含训练时段相邻小时），严格应做时序前向验证
